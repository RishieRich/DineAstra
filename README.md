# DineAstra

DineAstra is the starting point for a restaurant discovery and dining
experience project. The repository is connected to GitHub and is ready for
feature development.

## Development status

This repository is currently a clean project scaffold. Application code,
tooling, and automated tests will be added as development begins.

## Getting started

Clone the repository and enter the project directory:

```bash
git clone https://github.com/RishieRich/DineAstra.git
cd DineAstra
```

Once the application stack is selected, add the required install and run
commands here. Keep local secrets in an ignored `.env` file and document
required variables in a future `.env.example` file.

## Git workflow

Use focused branches and commits for new work:

```bash
git checkout -b feature/short-description
git add .
git commit -m "Describe the change"
git push -u origin feature/short-description
```
